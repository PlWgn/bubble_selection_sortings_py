## Сравнение пузырьковой сортировки и сортировки выбором на Python

Для исследования были реализованы два алгоритма сортировки: **Bubble Sort (пузырьковая сортировка)** и **Selection Sort (сортировка выбором)**.

Цель эксперимента — сравнить время выполнения алгоритмов на одинаковых случайно сгенерированных списках и проанализировать их временную сложность.

## Реализация пузырьковой сортировки

Данный скрипт демонстрирует работу алгоритма пузырьковой сортировки:

```python
def bubble_sort(arr):
    for i in range(len(arr) - 1):
        swapped = False

        for j in range(len(arr) - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True

        if not swapped:
            break

    return arr
```

Пузырьковая сортировка последовательно сравнивает соседние элементы списка. Если текущий элемент больше следующего, они меняются местами.

После каждого полного прохода наибольший элемент рассматриваемой части списка оказывается в конце. Таким образом, количество необходимых сравнений постепенно уменьшается.

В данной реализации используется дополнительный флаг `swapped`, который позволяет досрочно завершить сортировку, если во время очередного прохода не произошло ни одного обмена. Это означает, что список уже отсортирован.

## Реализация сортировки выбором

Данный скрипт демонстрирует работу алгоритма сортировки выбором:

```python
def selection_sort(arr):
    for i in range(len(arr)):
        min_index = i

        for j in range(i + 1, len(arr)):
            if arr[j] < arr[min_index]:
                min_index = j

        if i != min_index:
            arr[i], arr[min_index] = arr[min_index], arr[i]

    return arr
```

Сортировка выбором последовательно находит минимальный элемент в неотсортированной части списка и перемещает его на соответствующую позицию.

В отличие от пузырьковой сортировки, алгоритм не выполняет обмен при каждом обнаружении меньшего элемента. Вместо этого он запоминает индекс минимального значения и производит не более одного обмена за проход внешнего цикла.

Это позволяет сократить количество перестановок элементов.

## Временная сложность алгоритмов

Оба алгоритма относятся к сортировкам с квадратичной временной сложностью в среднем и худшем случаях.

### Пузырьковая сортировка

- **Лучший случай — O(n):** список уже отсортирован, поэтому алгоритм выполняет один проход без обменов и завершает работу благодаря флагу `swapped`.
- **Средний случай — O(n²):** требуется несколько проходов с последовательными сравнениями и обменами соседних элементов.
- **Худший случай — O(n²):** список расположен в обратном порядке, что приводит к большому количеству сравнений и перестановок.

### Сортировка выбором

- **Лучший случай — O(n²):** даже если список отсортирован, алгоритм продолжает искать минимальный элемент в оставшейся части.
- **Средний случай — O(n²):** на каждом проходе выполняется последовательный поиск минимального элемента.
- **Худший случай — O(n²):** алгоритм также проверяет все элементы оставшейся части списка.

В отличие от пузырьковой сортировки с флагом, сортировка выбором в данной реализации не имеет механизма досрочного завершения.

Однако она выполняет значительно меньше обменов элементов, что может положительно влиять на время выполнения.

Оба алгоритма используют **O(1) дополнительной памяти**, поскольку сортируют переданный список на месте.

Полученные результаты демонстрируют, что при сравнении алгоритмов необходимо учитывать не только их асимптотическую сложность, но и особенности работы с конкретными входными данными.
